Node.js & Vite

Développement avancé

Node.js

Introduction


Node.js est un environnement d'exécution JavaScript. Comme Python, il vous permet d'exécuter du JavaScript sur votre machine et d'en faire des applications.

Node.js permet, entre autres, de faire :

  • des serveurs web
  • des applications web
  • des applications desktop et en ligne de commande
  • des scripts
  • etc.

De même que Python possède son gestionnaire de paquets pip, Node.js possède npm (Node Package Manager).

Node.js est donc une application qui interprète du JavaScript et le transforme en instructions pour votre machine. Il existe certaines différences entre le JavaScript de Node et celui de votre navigateur. Par exemple, Node ne possède pas de DOM, car le script ne s'exécute pas dans une page web. Node fournit également un ensemble de fonctions permettant d'interagir avec votre système (créer des fichiers, gérer des processus, etc.), ce qui n'aurait pas de sens pour une page web. Il existe d'autres environnements d'exécution et d'autres gestionnaires de paquets que Node et npm. Nous utilisons ceux-ci car ce sont les plus répandus et les plus standards. Les alternatives ont souvent des fonctionnalités très similaires.

Node.js

Installation


Node.js se télécharge depuis le site officiel : https://nodejs.org/

  • Choisissez la version LTS (Long Term Support), stable et maintenue sur le long terme
  • npm est installé automatiquement avec Node.js

Pour vérifier l'installation, dans un terminal :


		node -v   # Affiche la version de Node.js
		npm -v    # Affiche la version de npm

npm fournit aussi la commande npx, qui permet d'exécuter un paquet sans l'installer dans le projet, par ex. npx prettier --write .

Sous Linux, Node.js est aussi disponible dans les gestionnaires de paquets de la distribution, mais la version proposée est parfois ancienne. Des outils comme nvm permettent d'installer et de basculer entre plusieurs versions de Node.js.

Node.js

Commandes

Quelques commandes de base, dans le répertoire d'un projet Node.js :

  • npm init : crée un nouveau projet Node.js à partir de zéro
  • npm install monPaquet : installe le paquet monPaquet, peut être abrégé npm i monPaquet
  • npm install : installe toutes les dépendances (paquets) du projet, peut être abrégé npm i
  • npm run maCommande : exécute la commande maCommande
  • npm -h : affiche l'aide des commandes

Contrairement à Python, par défaut, tous les paquets sont installés dans le répertoire du projet.
Chaque projet contient donc indépendamment tous ses paquets, ils ne sont pas partagés entre projets.

Node.js

Structure d'un projet

Un projet Node.js est notamment composé des fichiers / dossiers suivants :

  • package.json : liste les informations principales concernant un projet

		{
			"name": "monProjet",    // Nom du projet
			"type": "module",       // Les fichiers .js utilisent les modules ES (import / export)
			"scripts": {            // Liste des commandes (actions) disponibles pour le projet
				"dev": "vite",          // Exécuter "npm run dev" va exécuter la commande "vite"
				"build": "vite build",
				"preview": "vite preview"
			},
			"dependencies": {       // Liste des dépendances du projet,
				"librairie1": "^1.0.0", // ajoutées au moment d'un "npm install"
				"librairie2": "^1.2.0",
				"librairie3": "^2.3.0"
			}
		}

Les commentaires ne sont pas autorisés en JSON, ils sont présents ici uniquement à titre explicatif.

Node.js

Structure d'un projet

Un projet Node.js est notamment composé des fichiers / dossiers suivants :

  • package.json : liste les informations principales concernant un projet
  • package-lock.json : fichier généré automatiquement, qui fixe la version exacte de chaque dépendance installée
    Il doit être ajouté à votre dépôt git, pour que tout le monde installe exactement les mêmes versions
  • node_modules : dossier contenant toutes les dépendances téléchargées
    Il ne doit pas être ajouté à votre dépôt git, car il est souvent très lourd et recréé lors d'un npm install

Dans le fichier .gitignore :


		node_modules/

Vite

Introduction à Vite

Vite est un outil de développement web fonctionnant avec Node.js (entre autres). Il joue deux rôles :

  • Serveur de développement : sert votre application en local et la recharge instantanément à chaque modification du code (Hot Module Replacement, HMR)
  • Bundler : au moment du build, prend un ensemble de fichiers JavaScript, HTML, CSS, images, etc. et produit une application web rapide et minimale

Vite

Avantages

Les avantages de Vite sont :

  • Gestion moderne des dépendances : les dépendances sont installées en ligne de commande avec npm et incluses avec du JavaScript moderne (import)
  • Résultat minimal : Vite n'inclut que les parties de code réellement utilisées et minifie le résultat
  • Ajout facile d'autres technologies : Vue, TypeScript, SCSS, Svelte, React, etc.

Vite s'intègre aussi facilement aux outils de l'écosystème npm : mise en forme automatique, tests, scripts lors d'un commit, intégration continue, etc.

Ce bundler est tellement utilisé que certaines librairies en font leur moyen de diffusion principal. C'est le cas d'OpenLayers.

Les outils comme Prettier (mise en forme), Vitest (tests) ou Husky (scripts de commit) ne font pas partie de Vite, mais s'installent avec npm et s'intègrent naturellement à un projet Vite.

Vite

Créer un projet


Vite fournit un assistant pour créer un nouveau projet :


		npm create vite@latest

L'assistant demande :

  • le nom du projet (et donc du dossier créé)
  • le framework : choisir Vanilla (JavaScript pur, sans framework)
  • la variante : choisir JavaScript

Il suffit ensuite d'installer les dépendances et de lancer le serveur de développement :


		cd monProjet
		npm install
		npm run dev

Vite

Commandes


Un projet Vite contient par défaut trois commandes, définies dans package.json :

  • npm run dev : lance le serveur de développement (par défaut sur http://localhost:5173), avec rechargement automatique à chaque modification
  • npm run build : produit la version de production de l'application dans le dossier dist/
  • npm run preview : sert en local le contenu de dist/, pour tester la version de production

Le dossier dist/ contient uniquement des fichiers HTML, CSS, JavaScript et des ressources statiques. Il peut être déployé tel quel sur n'importe quel serveur web, sans Node.js.

Comme node_modules, il est généré : il ne doit pas être ajouté au dépôt git.
