Installation

OpenLayers est distribué comme paquet npm. Dans un projet Vite existant :


		npm install ol
		npm install proj4    # Nécessaire pour la projection suisse, voir plus loin

OpenLayers fournit aussi un modèle de projet prêt à l'emploi, basé sur Vite :


		npx create-ol-app monProjet
		cd monProjet
		npm start

Ce modèle contient déjà les fichiers index.html, main.js et style.css présentés dans les slides suivantes.

Le script principal est ensuite inclus, comme dans un projet Vite de base.

Le CSS

Sans hauteur définie, le <div> mesure 0 pixel de haut : la carte est bien créée, mais invisible !

OpenLayers

La Map

C'est l'objet de base, il représente la carte affichée à l'écran.

Propriétés :

  • target : id de l'élément dans lequel créer la Map
  • view : objet View qui décrit la vue à afficher dans la carte
  • layers : tableau d'objets Layer qui décrivent les couches présentes sur la carte

Propriétés facultatives :

  • controls : tableau d'objets Control, éléments d'interface affichés sur la carte (zoom, rotation, plein écran, etc.)
  • interactions : tableau d'actions auxquelles la carte doit réagir (clic, double-clic, glisser-déposer, etc.)

D'autres propriétés existent, voir https://openlayers.org/en/latest/apidoc/module-ol_Map-Map.html

Webmapping

OpenLayers

La Map


		import 'ol/ol.css';
		import './style.css';
		import Map from 'ol/Map.js';

		const map = new Map({
			target: 'map',          // 'target' est l'id du div à utiliser comme carte
			view: /* À venir */,
			layers: /* À venir */
		});

Dans OpenLayers, les paramètres sont toujours passés à l'aide d'un objet. On écrira :


		new Map({target: 'map', view: undefined, layers: undefined});

Et non pas :


		new Map('map', undefined, undefined);

Webmapping

OpenLayers


La View

Objet qui décrit la résolution, la rotation, la position, la projection, etc. de la Map

Propriétés :

  • center : tableau contenant les coordonnées du centre de la carte
  • zoom : nombre décrivant le niveau de zoom

Autres propriétés :

  • resolution : alternative à zoom, qui décrit la résolution de la carte
  • projection : la projection de la vue

D'autres propriétés existent, voir https://openlayers.org/en/latest/apidoc/module-ol_View-View.html

Webmapping

OpenLayers


La View


		import 'ol/ol.css';
		import './style.css';
		import Map from 'ol/Map.js';
		import View from 'ol/View.js';

		const map = new Map({
			target: 'map',
			view: new View({        // La View indique comment la Map doit être affichée
				center: [0, 0],     // Ici centrée en (0, 0)
				zoom: 2,            // Et avec un zoom à 2
			}),
			layers: /* À venir */
		});

On remarque que Map et View prennent en paramètre un objet qui contient toutes les valeurs des paramètres.

OpenLayers


Les Layers

Il existe plusieurs types de layers (module ol/layer), mais ils peuvent être divisés en 2 catégories :

  1. Raster (par ex. : TileLayer, ImageLayer)
  2. Vectoriel (par ex. : VectorLayer, VectorTileLayer)

La source de la donnée (module ol/source) est une propriété d'un layer et existe aussi en 2 catégories :

  1. Raster (par ex. : TileSource, ImageSource)
  2. Vectoriel (par ex. : VectorSource, VectorTileSource)

Un exemple de TileSource est un objet OSM qui indique une couche OpenStreetMap.

Webmapping

OpenLayers


Code complet de main.js


		import 'ol/ol.css';
		import './style.css';
		import Map from 'ol/Map.js';
		import OSM from 'ol/source/OSM.js';
		import TileLayer from 'ol/layer/Tile.js';
		import View from 'ol/View.js';

		const map = new Map({
			target: 'map',
			view: new View({
				center: [0, 0],
				zoom: 2,
			}),
			layers: [               // Liste des layers à afficher
				new TileLayer({     // Dans ce cas, il y a un layer tuilé, OpenStreetMap (OSM)
					source: new OSM(),
				}),
			],
		});

Les contrôles

Les contrôles sont des éléments permettant de manipuler la carte ou d'afficher une information.
Par défaut, Map en charge trois :

  • Zoom : permet de zoomer sur la carte
  • Rotate : orientation (apparaît dès que la carte est tournée)
  • Attribution : copyright des données

OpenLayers

Les événements

La Map émet des événements auxquels on peut réagir avec la méthode on() :


		// Clic sur la carte
		map.on('click', (event) => {
			console.log('Clic en', event.coordinate); // Dans la projection de la View
		});

		// Déplacement de la souris : affiche les coordonnées dans un <div id="position">
		map.on('pointermove', (event) => {
			document.getElementById('position').textContent = event.coordinate.join(', ');
		});

		// Fin d'un déplacement ou d'un zoom de la carte
		map.on('moveend', () => {
			console.log('Nouveau zoom :', map.getView().getZoom());
		});

Liste des événements : voir la section Fires de https://openlayers.org/en/latest/apidoc/module-ol_Map-Map.html

La projection suisse EPSG:2056

Par défaut, OpenLayers ne connaît pas la projection suisse. Il faut la lui définir.


		import proj4 from 'proj4';
		import { register } from 'ol/proj/proj4.js';
		import { get as getProjection } from 'ol/proj.js';

		proj4.defs(
			'EPSG:2056',
			'+proj=somerc +lat_0=46.95240555555556 +lon_0=7.439583333333333 +k_0=1 +x_0=2600000' +
			' +y_0=1200000 +ellps=bessel +towgs84=674.374,15.056,405.346,0,0,0,0 +units=m +no_defs',
		);
		register(proj4);
		// Étendue de validité de la projection (la Suisse)
		getProjection('EPSG:2056').setExtent([2420000, 1030000, 2900000, 1350000]);

Ces lignes sont à ajouter au début de votre script, avant tout appel à OpenLayers.

Webmapping

OpenLayers


La projection suisse EPSG:2056

Une fois définie, la projection peut être utilisée dans la View :


		const map = new Map({
			target: 'map',
			view: new View({
				projection: 'EPSG:2056',       // La View utilise maintenant la projection suisse
				center: [2561000, 1204500],    // Les coordonnées sont en mètres MN95 (ici Neuchâtel)
				zoom: 5,
			}),
			layers: [ /* ... */ ],
		});

Toutes les coordonnées manipulées par la carte (centre, clics, etc.) sont alors exprimées en EPSG:2056.

OpenLayers


Un fond de carte suisse : la carte nationale de swisstopo

En EPSG:2056, les tuiles swisstopo suivent une grille qui leur est propre, qu'il faut décrire à OpenLayers :


		import TileGrid from 'ol/tilegrid/TileGrid.js';

		// Résolutions (mètres par pixel) des tuiles swisstopo en EPSG:2056
		const resolutions = [4000, 3750, 3500, 3250, 3000, 2750, 2500,
			2250, 2000, 1750, 1500, 1250, 1000, 750, 650, 500, 250,
			100, 50, 20, 10, 5, 2.5, 2, 1.5, 1, 0.5, 0.25];

		const tileGrid = new TileGrid({
			origin: [2420000, 1350000],   // Coin supérieur gauche de la grille de tuiles
			resolutions: resolutions,
		});

Webmapping

OpenLayers


Un fond de carte suisse : la carte nationale de swisstopo

La couche utilise ensuite cette grille pour charger les tuiles :


		import XYZ from 'ol/source/XYZ.js';

		const swisstopo = new TileLayer({
			source: new XYZ({
				url: 'https://wmts.geo.admin.ch/1.0.0/ch.swisstopo.pixelkarte-farbe'
					+ '/default/current/2056/{z}/{x}/{y}.jpeg',
				projection: 'EPSG:2056',
				tileGrid: tileGrid,
				attributions: '© swisstopo',
			}),
		});

Documentation et autres couches disponibles : https://docs.geo.admin.ch/visualize-data/wmts.html

Un fond de carte suisse : la carte nationale de swisstopo

Enfin, la couche est ajoutée à la carte :


		const map = new Map({
			target: 'map',

				projection: 'EPSG:2056',
				resolutions: resolutions,      // Mêmes résolutions que les tuiles : affichage net

				zoom: 18,                      // Résolution n°18 : 50 m/pixel
			}),
			layers: [swisstopo],
		});
