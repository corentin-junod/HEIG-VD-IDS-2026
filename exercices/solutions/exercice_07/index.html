Exercice 07

Dans cet exercice, vous allez écrire plusieurs fois le même programme : d'abord avec des callbacks, puis avec des promesses, puis avec async / await.

Tout se passe dans le fichier main.js. Ouvrez la console de votre navigateur pour voir le résultat des tests.


Contexte

Le fichier main.js contient un faux serveur cartographique, dans la section "Code fourni". Il simule un serveur distant : chaque fonction répond après un délai aléatoire, en appelant un callback. Ne modifiez pas ce code, mais lisez-le pour comprendre ce que chaque fonction retourne.

  • loadCapabilities(url, callback) : charge la description du service. Le callback reçoit un objet contenant la liste des couches disponibles, chacune avec un id et un name
  • loadLayer(id, callback) : charge une couche à partir de son id (et non de son nom). Le callback reçoit un objet contenant l'URL de ses entités, featuresUrl
  • loadFeatures(featuresUrl, callback) : charge les entités d'une couche. Le callback reçoit un tableau d'entités

Tous les callbacks suivent la même convention : callback(resultat, erreur). En cas de succès, erreur vaut null. En cas d'échec, resultat vaut null et erreur contient un objet Error.

L'objectif est toujours le même : compter le nombre d'entités d'une couche, à partir de son nom. Pour cela, il faut charger la description du service, y trouver l'id de la couche, charger la couche, puis charger ses entités.

La méthode find des tableaux vous sera utile pour trouver une couche par son nom.


Partie 1 : Callbacks

  1. Complétez la fonction countFeaturesCallback(url, layerName, callback), en utilisant uniquement les fonctions à callback du serveur
  2. En cas de succès, elle appelle callback(nombreEntites, null)
  3. En cas d'erreur à n'importe quelle étape, elle appelle callback(null, erreur). Si la couche demandée n'existe pas dans la description du service, l'erreur est à créer vous-même avec new Error(...)

Observez la forme de votre code : c'est le callback hell.


Partie 2 : Promesses

  1. Complétez les fonctions loadCapabilitiesPromise, loadLayerPromise et loadFeaturesPromise. Elles font la même chose que les fonctions du serveur, mais retournent une promesse au lieu de prendre un callback. Utilisez new Promise((resolve, reject) => ...)
  2. Complétez la fonction countFeaturesPromise(url, layerName), qui retourne une promesse du nombre d'entités. Utilisez uniquement les fonctions écrites au point précédent, et enchaînez-les avec then
  3. En cas d'erreur, la promesse retournée doit être rompue. Pour une couche inexistante, il suffit de lever une exception avec throw dans un then

Partie 3 : async / await

  1. Complétez la fonction countFeaturesAsync(url, layerName), qui fait la même chose que countFeaturesPromise, mais en utilisant async et await
  2. Répondez en commentaire dans main.js : pourquoi est-il impossible d'écrire une fonction countFeaturesSync(url, layerName), sans async, qui retourne directement le nombre d'entités ?

Partie 4 : Plusieurs couches

Complétez les fonctions suivantes, qui retournent toutes les deux une promesse d'un objet de la forme { batiments: 152, routes: 87, ... }, contenant le nombre d'entités de chaque couche du service :

  1. countAllLayersSequential(url), qui charge les couches les unes après les autres
  2. countAllLayersParallel(url), qui charge toutes les couches en même temps, à l'aide de Promise.all

Les tests affichent la durée de chaque version. Comparez-les.


Partie 5 (bonus) : Erreurs réseau

Le faux serveur peut simuler des erreurs réseau : la variable failureRate indique la probabilité qu'un appel à loadFeatures échoue. Ces erreurs sont de type NetworkError, une classe qui hérite de Error.

  1. Complétez la fonction countFeaturesWithRetry(url, layerName, maxAttempts), qui fonctionne comme countFeaturesAsync, mais qui réessaie tant qu'une NetworkError se produit, au maximum maxAttempts fois
  2. Les autres erreurs (par exemple une couche inexistante) ne doivent pas être réessayées : la promesse doit être rompue immédiatement
  3. Si toutes les tentatives échouent, la promesse est rompue avec la dernière erreur

Indice : instanceof permet de savoir si une erreur est d'un type donné.


Le bas du fichier main.js contient des tests, qui servent aussi d'exemples d'utilisation de toutes les fonctions décrites ci-dessus. Une fois l'exercice terminé, ce fichier ne doit afficher aucune erreur dans la console.
