# Infrastructures et développement des SIG (IDS)

https://www.jmdt.ch/presentation/modules-et-ateliers/infrastructures-et-developpement-des-sig

Ce dépôt contient le contenu de la deuxième partie du cours : Développement géoinformatique avec le langage Javascript

## Évaluation

Le module est évalué par un projet de groupe:
- Rendu du projet en groupe (qualité du code, respect de consignes, cohérence des fonctionnalités, etc) : 25% de la note du cours
- Présentation du projet (qualité de la présentation, compréhension et maîtrise du code et des concepts vu en cours, etc) : 25% de la note du cours

### Projet

Le projet consiste à développer, par groupe, une application web mettant en application les notions vue en cours.
Les détails seront annoncés au moment de commencer les projets.
